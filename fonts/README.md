# Fonts

`fixedsys-excelsior.woff` — Fixedsys Excelsior 3.01 by Darien Gavin Valentine, a recreation of the
Windows Fixedsys raster font (the Notepad default in Windows 95/98). Used by the front page (etusivu.css).

License: public domain, with a CC0 fallback where public domain dedication isn't recognised
(https://github.com/kika/fixedsys). No attribution or notice is required; this credit is a courtesy.

The file came via the npm package `fixedsys-css`; that package's own MIT license covers its CSS,
not the font, so it isn't included here.

Designed on a 16px grid: use it at 16px (or multiples) to keep it crisp.
